SAFARI EXTENSION

Manga Sub

Dịch truyện ngay trên Safari cho iPhone và iPad.

Bật một lần

  1. Mở Cài đặt → Ứng dụng → Safari → Phần mở rộng.
  2. Enable Manga Sub and allow access to comic websites.
  3. In Safari, tap the extensions button in the address bar and select Manga Sub.

Dùng server riêng

Bản iPhone/iPad đã đặt sẵn https://comic-be.dep.app/api/v1. Chỉ cần nhập Auth key nếu server có bật bảo vệ. Cùng một backend dùng được cho Chrome, iPhone và iPad.

Mở trang truyện thử

Safari trên iPhone/iPad cần server HTTPS truy cập được từ Internet hoặc mạng nội bộ; localhost trên máy tính sẽ không dùng được.
